# Codex Usage HUD 0.5.0 Preview

Codexの利用枠残量と処理中のActivityを表示する、macOS用の小型常駐HUDです。無料Preview版として公開します。

## 重要: ダウンロード前に確認してください

- OpenAIおよびAppleの公式製品ではありません。
- macOS専用です。Windowsでは動作しません。
- このPreview版はApple Developer IDで署名・公証されていません。
- 初回起動時に「Appleは悪質なソフトウェアが含まれていないことを確認できません」などの警告が表示されます。
- 配布元とSHA-256を確認し、信頼できる場合だけ使用してください。

Appleによる未公証アプリの説明と開き方:
https://support.apple.com/102445

## ダウンロード

Assetsから次のファイルを選んでください。

- アプリ本体: `Codex-Usage-HUD-0.5.0-preview-mac.zip`
- 取扱説明書: `Codex-Usage-HUD-取扱説明書-0.5.0.pdf`

GitHubが自動表示する `Source code (zip)` はアプリ本体ではありません。

## インストール

1. ZIPを展開します。
2. `Codex Usage HUD.app` を「アプリケーション」フォルダへ移動します。
3. アプリを開きます。
4. Appleの警告が出た場合は、取扱説明書の手順を確認してください。
5. HUDメニューから「Codex Hooksをインストール…」を選びます。
6. Codexを再起動し、`/hooks` で内容を確認して信頼します。

## 表示内容

- Activity LED: 処理時間に応じた警告灯
- LOAD: 直前処理との時間比
- PEAK: 当日の最大Activityレベル
- REMAIN: Codexが返した現在の利用枠残量

LOADとPEAKは正確なトークン数ではありません。REMAIN取得はCodex app-serverの内部的な利用枠情報に依存するため、将来のCodex更新で動作しなくなる可能性があります。
