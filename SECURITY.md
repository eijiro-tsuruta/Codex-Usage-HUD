# Security

## Safe downloads

Download Codex Usage HUD only from this repository's Releases page. Verify the SHA-256 value published in the release notes before opening the ZIP.

The current Preview build is not signed or notarized with an Apple Developer ID. macOS will therefore show a security warning on first launch. Do not disable Gatekeeper globally.

## Reporting a security issue

Open a GitHub issue without including secrets or private data. Do not attach authentication tokens, API keys, prompts, project files, or unredacted logs. If GitHub private vulnerability reporting is enabled for this repository, use that channel for sensitive reports.
